Enviar vendas ao computador

Exporte as vendas e importe o arquivo JSON na versão completa do Windows. Vendas já importadas não serão duplicadas.

No iPhone, salve o arquivo em Arquivos ou compartilhe pelo AirDrop. No Windows, abra a opção de importar vendas.

Atualizar produtos e estoque

Importe um backup JSON da versão do computador. Para proteger as vendas ainda não transferidas, esta ação é bloqueada enquanto houver vendas locais pendentes de exportação.

O backup completo deve ser gerado no Windows. Esta versão móvel importa apenas o cadastro e as quantidades do estoque.

Segurança dos dados

A transferência é manual. A sincronização automática por Wi-Fi ainda não foi implementada.
